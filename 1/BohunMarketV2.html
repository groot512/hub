카테고리 개편 (New Strategy)

타겟 사용자별 라이프스타일을 반영한 7대 핵심 카테고리

신설/통합 기존 개선

푸드/카페

맛집, 카페, 베이커리

Key Point: 식품/반찬(New)

1인 가구 및 주부 타겟 식재료 구매처 통합

의료/건강

병원, 약국, 안경

Key Point: 재활/케어/보청기

고령 유공자 맞춤형 의료기기 및 케어 서비스 강화

생활/반려

Update

마트, 편의점, 생활용품

Key Point: 반려동물(Pet) 격상

기존 생활/쇼핑에서 분리, 펫팸족 집중 공략

뷰티/패션

Update

헤어, 바버샵, 세탁

Key Point: 의류/잡화 통합

'꾸밈' 욕구 충족을 위해 의류와 뷰티 서비스 통합

차량/기술

주유, 정비, 세차

Key Point: 기술 전문성 강조

단순 수리를 넘어 엔지니어 전문성 부각

교육/육아

Update

학원, 교습소, 문구

Key Point: 교육 전용 카테고리

기존 여가 카테고리와 분리하여 학부모 타겟 집중

여행/레저

Update

숙박, 캠핑, 스포츠

Key Point: 신설 카테고리

보훈 급여 활용 여가 층 공략 (공방, 스크린골프 등)

플랫폼 생태계 확장

사용자, 사장님, 그리고 지원센터가 유기적으로 연결됩니다

사용자 앱

  • OCR 리더 도입: 신분증 스캔으로 간편 회원가입
  • 내역 조회 강화: 할인 및 사용 내역 실시간 확인
  • 고령층 유공자 대상 전용 카드 발급 연계
  • 개인화 프로필: 내 정보 수정 및 맞춤 혜택 제공

사장님 전용

  • QR 리더 장착: 바코드로 유공자 사용 기록 데이터화
  • 이벤트 푸시: '자장면 데이' 등 타겟 마케팅 발송
  • 매장 관리: 예약, 테이블오더, 식자재 구매 연동
  • 기부금 영수증: 향후 발급 가능하도록 데이터 기반 마련

상생지원센터

  • 수익 분배 로직: 센터장, 매니저, 본사 자동 정산
  • 매니저용 지도(Map): 가맹점 관리 효율성 증대
  • API 활용: 네이버 지도 기반 위치 데이터 시각화
  • 전용 앱 구축: 현장 매니저 업무 최적화

비즈니스 확대 전략 제안

보편적이고 안정적인 서비스를 위한 3가지 핵심 축

선순환 기부 모델 (Social)

가맹점 이용 시 매출 일부가 보훈 기금으로 적립. 사장님에게는 명분을, 유공자에게는 자부심을 제공하여 지속 가능한 생태계 조성.

데이터 큐레이션 (Curation)

고령층(병원/반찬) vs MZ세대(캠핑/맛집) 타겟별 맞춤 홈 화면 구성. 위치 및 연령 기반 자동 추천 알고리즘 도입.

Phygital 멤버십

실물 카드(고령층)와 앱 결제(NFC/QR)를 통합한 '보훈 페이' 확장. 기술 소외 없이 누구나 혜택을 누리는 유니버설 서비스.
