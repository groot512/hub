# 구미시 K-Food 해외 수출 지원 센터 — 사업 제안 보고서

신임 구미시장 보고용 인터랙티브 웹 보고서입니다. 기존 PDF 보고서를 내용 보완 + 스토리텔링형 원페이지 웹사이트로 재구성했습니다.

## 보기

`index.html`을 브라우저로 열면 됩니다. (인터넷 연결 시 폰트·차트가 정상 표시됩니다)

```
index.html  ← 더블클릭
```

> ⚠️ `index.html`을 옮길 때는 `hero-bg.jpg`, `mexico-bg.jpg`도 같은 폴더에 함께 두어야 배경이 보입니다.
