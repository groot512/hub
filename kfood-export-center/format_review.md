# 🎨 형식(디자인·레이아웃) 검토 보고서

**대상**: 구미시 "K-Food 해외 수출 지원 센터" 사업 타당성 검토 및 실행 계획  
**검토일**: 2026년 6월 27일  
**목적**: 현재 PDF 보고서를 세련된 인터랙티브 웹 보고서로 전환하기 위한 형식 검토

---

## 1. 현재 형식의 문제점

### 1.1 PDF 보고서의 한계

| 문제점 | 영향 |
|--------|------|
| 📄 정적인 PDF 형식 | 스크롤만 가능, 인터랙션 없음. 시장님이 흥미를 잃기 쉬움 |
| 📊 표가 깨져 보임 | PDF에서 표의 셀이 줄바꿈으로 분리되어 가독성 저하 |
| 🎨 디자인 없음 | 이모지(🏗️💰🤖)만으로 시각적 구분, 전문적이지 않음 |
| 📱 모바일 비대응 | 태블릿/스마트폰에서 열기 불편 |
| 🔗 공유 제한적 | Z.AI 공유 링크로는 실제 콘텐츠 렌더링이 불안정 |

### 1.2 시각적 요소 진단

- ❌ **차트/그래프 0개** — 250억 예산, KPI 목표 등 숫자가 많으나 모두 표로만 제시
- ❌ **이미지/아이콘 0개** — 멕시코 거점, 물류센터 등의 시각적 표현 없음
- ❌ **타임라인 없음** — 단계별 일정이 텍스트로만 나열
- ❌ **색상 체계 없음** — 흑백 텍스트 위주
- ⚠️ **이모지 과다 사용** — 🏗️💰🤖📋⚠️🎯 등 이모지가 섹션 구분 역할을 하고 있으나 공식 보고서에는 부적합

## 2. 웹 보고서 전환 전략

### 2.1 추천 형식: **원페이지 스크롤링 웹 보고서**

> [!TIP]
> 신임 시장에게 "이 사업의 미래"를 보여주는 것이 목적이므로, **스토리텔링형 풀페이지 스크롤링 웹사이트**가 가장 적합합니다.

**참고 레퍼런스 스타일:**
- Apple 제품 소개 페이지 (스크롤 애니메이션 + 대담한 타이포그래피)
- 정부/지자체 정책 홍보 사이트 (데이터 시각화 + 인포그래픽)
- Stripe/Linear 스타일 (깔끔한 다크/라이트 테마 + 그래디언트)

### 2.2 제안 섹션별 시각 요소

| 섹션 | 현재 형식 | 웹 보고서 제안 |
|------|----------|---------------|
| 히어로 (신규) | 없음 | 🌆 구미시 전경 + 사업 비전 슬로건의 풀스크린 히어로 |
| Executive Summary (신규) | 없음 | 📊 핵심 숫자 4개를 애니메이션 카운트업으로 표시 |
| 현황 분석 | 텍스트 나열 | 📈 인구 추이 라인 차트 + 산업 구조 도넛 차트 |
| 왜 멕시코인가 | 1줄 언급 | 🗺️ 세계 지도 위 멕시코 하이라이트 + 시장 규모 인포그래픽 |
| 타당성 분석 | 불릿 리스트 | ✅ 3개 카드 (정책·경제·기술) 호버 효과 |
| 인프라 계획 | 깨진 표 | 🏢 아이소메트릭 인프라 다이어그램 또는 아이콘 카드 |
| 기업 유치 | 텍스트 | 🔄 3단계 수평 타임라인 스텝퍼 |
| 멕시코 거점 | 텍스트 | 🇲🇽 MOU 로드맵 타임라인 + 파트너 로고 |
| 예산 | 표 | 💰 도넛 차트 (항목별) + 스택드 바 차트 (재원별) |
| KPI | 표 | 📊 연도별 목표 비교 바 차트 + 게이지 차트 |
| 리스크 | 표 | ⚡ 히트맵 매트릭스 (발생 가능성 × 영향도) |
| 기대 효과 | 불릿 리스트 | 🎯 아이콘 + 수치 강조 그리드 |
| 결론 | 텍스트 | 🚀 CTA(Call to Action) 스타일 마무리 |

## 3. 디자인 시스템 제안

### 3.1 컬러 팔레트

```
메인 컬러:
├── Primary: #1B4332 (딥 그린 — 식품·농업·성장의 이미지)
├── Secondary: #D4A574 (골드 브라운 — K-Food 따뜻한 느낌)
├── Accent: #E63946 (한국 전통 적색 — 고추장·매운맛)
├── Dark BG: #0A1628 (네이비 다크 — 고급스러운 배경)
└── Light BG: #F8F9FA (밝은 그레이 — 가독성)

보조 컬러:
├── 멕시코 그린: #006847 (멕시코 국기)
├── 성공/성장: #2D6A4F
└── 경고/리스크: #F4845F
```

### 3.2 타이포그래피

```
제목: Pretendard Bold (800) — 한글 가독성 최적
부제목: Pretendard SemiBold (600)
본문: Pretendard Regular (400), line-height: 1.8
숫자 강조: Outfit Bold — 영문/숫자 임팩트
```

### 3.3 애니메이션 전략

| 요소 | 애니메이션 | 용도 |
|------|----------|------|
| 섹션 진입 | Fade-up + Slide-in | 스크롤 시 콘텐츠가 자연스럽게 등장 |
| 숫자 | Count-up | 250억, 500억, 300명 등 KPI 수치 강조 |
| 차트 | Draw-in | 차트가 그려지는 효과 |
| 타임라인 | Progressive reveal | 스크롤에 따라 단계가 순차 노출 |
| 카드 | Hover lift | 마우스 올리면 살짝 떠오르는 효과 |

## 4. 기술 스택 추천

| 항목 | 추천 기술 | 이유 |
|------|----------|------|
| 프레임워크 | **Vanilla HTML/CSS/JS** | 별도 서버 없이 정적 파일로 배포 가능 |
| 차트 | **Chart.js** 또는 **CSS 기반** | 가볍고 커스터마이징 자유로움 |
| 스크롤 애니메이션 | **Intersection Observer API** | 네이티브 브라우저 API, 외부 라이브러리 불필요 |
| 폰트 | **Pretendard** (CDN) + **Outfit** (Google Fonts) | 한글+영문 최적 조합 |
| 배포 | **GitHub Pages** 또는 **로컬 파일** | 무료, 링크 공유 가능 |
